Beauty by Belle - Webseite (statisch, ohne Build)

1. Alle Dateien (nicht den Ordner) in ein neues GitHub-Repository hochladen.
2. Repository > Settings > Pages > Branch "main" / Ordner "/ (root)" wählen.
3. Optional: Fotos in den Ordner images/ legen. Studio-Foto als images/studio.jpg (erscheint im Bogen auf der Startseite).
4. In impressum.html Name und E-Mail eintragen.
